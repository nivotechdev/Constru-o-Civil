# Rotas do app (55) — `web/src/routes.ts` + `App.tsx` + `services/guards.ts` (agente C6)

Guardas: **public** = qualquer um, inclusive no meio do onboarding; **guest** = só sem sessão (com sessão → `homeFor`: `/verificar-email` → `/completar-perfil/<papel>` → `/aceitar-termos` → `/mural`); **onboarding** = com sessão, só o passo atual; **app** = logado e completo, qualquer papel (sem sessão → `/login` + `return-to`); **trabalhador/recrutador** = só o papel (errado → tela "Essa área é da conta de…"). Caminho sem rota → `PageNotFound`; `/` → `/splash`. Moldura: T = tela cheia (`isAuthFlow`), B = dentro do `AppShell` (barra); barra de baixo no celular só nas abas (trabalhador: /mural, /minhas-candidaturas, /perfil; empresa: /mural, /minhas-vagas, /criar-vaga, /empresa).
